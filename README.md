# 서술형 연습 웹앱 — 5-2 과학 「열과 우리 생활」

연습 문항 8개를 학생과 함께 풀고, 교사가 반별·문항별로 답을 한 번에 확인하는 웹앱입니다. 설계 내용은 [설계도.md](설계도.md)를 보세요.

## 1. 수업 모드 (학생 답을 모아 보기)

필요한 것: Node.js 18 이상(이 PC에는 설치되어 있음). 추가 설치는 필요 없습니다.

1. `서버켜기.bat`을 더블클릭합니다(또는 이 폴더에서 `npm start`).
2. 처음 실행하면 `local/config.json`이 만들어지고 **교사 PIN**이 창에 표시됩니다. PIN은 이 파일에서 바꿀 수 있습니다.
3. Windows 방화벽 창이 뜨면 **개인 네트워크 허용**을 누릅니다(학생 기기 접속에 필요).
4. 교사 화면: `http://localhost:8080/teacher.html` → PIN 입력 → [+ 반 만들기]
5. [학생 접속 주소]를 눌러 주소와 QR을 큰 화면에 띄웁니다. 예: `http://172.30.2.122:8080/`
6. 학생은 반·번호·이름으로 참여합니다.

### 진행 방법
- **실시간 진행**: 문항 선택 → 1~5분 선택 → [시작]. 학생 화면에 문항과 카운트다운이 뜨고, 시간이 끝나면 자동으로 제출됩니다. [정답 공개]를 누르면 학생이 예시 답안과 채점 기준을 보며 스스로 점검합니다.
- **자유 연습**: 학생이 문항을 골라 풉니다. 문항당 제한 시간(없음, 1~5분)은 교사가 정합니다.
- **정답 공개 시점**: ‘제출 즉시’ 또는 ‘교사가 공개할 때’ 중에서 고릅니다.
- **확인**: [문항별 보기]에서 학생 × 소문항 표를 봅니다. 핵심 낱말 일치 표시를 참고해 점수와 피드백을 입력합니다. ‘답 모아 보기’로 한 소문항의 답을 카드로 모아 봅니다. [반 전체 보기]에서 8문항의 제출 현황과 점수를 봅니다.
- **큰 화면**: 남은 시간과 제출 인원을 전자칠판에 크게 띄웁니다. ‘이름 가리기’를 켜면 번호만 보입니다.
- **CSV 내보내기**: 반별 답안·점수를 엑셀로 엽니다.

## 2. 혼자 연습 모드 (GitHub Pages)

`docs/` 폴더를 GitHub Pages로 공개하면 서버 없이 학생 혼자 풀 수 있습니다. 답은 학생 기기의 브라우저에만 저장되고, 제출하면 바로 정답이 보입니다.

1. GitHub에서 새 저장소를 만듭니다(예: `seosul-practice`).
2. 이 폴더에서 다음 명령을 실행합니다.
   ```bash
   git add .
   git commit -m "서술형 연습 웹앱"
   git branch -M main
   git remote add origin https://github.com/<내 아이디>/seosul-practice.git
   git push -u origin main
   ```
3. 저장소 Settings → Pages → Branch: `main`, 폴더: `/docs` → Save
4. 몇 분 뒤 `https://<내 아이디>.github.io/seosul-practice/` 에서 열립니다.

## 3. 개인정보·키 보관 원칙

| 무엇 | 어디에 | GitHub에 올라가나 |
|---|---|---|
| 코드, 연습 문항, 설계도 | 이 폴더 | 올라감(공개) |
| 교사 PIN, API 키 | `local/config.json` | **올라가지 않음** (`.gitignore`) |
| 반, 학생 이름·번호, 답안, 점수 | `local/data/` | **올라가지 않음** |
| CSV 내보내기 파일 | 다운로드 폴더 | 올라가지 않음 (`*.csv` 제외) |

- 연습 문항의 예시 답안은 `docs/questions.json`에 있어 공개 저장소에서는 누구나 볼 수 있습니다. 실전 평가 문항은 이 저장소에 넣지 마세요.
- 학기 말에 `local/` 폴더를 지우면 학생 정보가 모두 삭제됩니다.

## 4. 문제 해결

- **학생이 접속하지 못함**: 같은 와이파이인지, 방화벽에서 Node.js가 허용되었는지 확인하세요. 학교망이 기기끼리 통신을 막는 경우(무선 격리)에는 정보 담당 선생님께 문의하거나 혼자 연습 모드를 쓰세요.
- **PIN을 잊음**: `local/config.json`을 메모장으로 열어 확인하거나 바꾼 뒤 서버를 다시 켭니다.
- **포트 변경**: `local/config.json`의 `port` 값을 바꿉니다.
